# DuelArena (Purpur / Paper 1.21.8, Java 21)

PvP-дуэли 1 на 1 в временных кабинках.

- `/duel <ник>` — вызвать игрока. Ему приходит сообщение с кнопками [ПРИНЯТЬ] / [ОТКЛОНИТЬ].
  Отказ: «<ник> с позором отклонил приглашение на дуэль игрока <ник>» (на весь сервер, config: broadcast-decline).
- Принял — создаётся отдельный void-мир (duel_world) и для пары строится остров (диаметр ~40, блоки можно ставить/ломать)
  в случайных координатах, окружённый барьером. Несколько пар одновременно — у каждой своя кабинка.
- Отсчёт 5 сек, затем бой. Анти-релог: выход с сервера во время боя = поражение (вещи падают на остров).
- Во время дуэли команды отключены (кроме `/duel leave` после боя; право duel.admin обходит запрет).
- Проигравший умирает, его лут остаётся на острове. Победитель собирает лут и вводит `/duel leave`.
- Когда оба покинули остров (или через after-fight-seconds) кабинка стирается и чанки выгружаются.
- Падение с острова в пустоту = смерть.

Структура: DuelsPlugin, DuelManager (вся логика), DuelListener (события), DuelCommand. Настройки: config.yml.
